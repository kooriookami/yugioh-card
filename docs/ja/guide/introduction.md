# はじめに

Yugioh Card は、LeaferJS を使って遊戯王カードを描画するオープンソースのライブラリです。カード名、カードイラスト、カードテキストなどのデータを渡すと、指定したレイアウトでカードを描画できます。

対応するレイアウトは、遊戯王、ラッシュデュエル、遊戯王カードの裏面、フィールドセンターカード、遊戯王 第2期の 5 種類です。指定できる項目とサンプルは [API リファレンス](../reference/) を参照してください。

## 用途

- **カードエディター**を作り、カード名やイラスト、テキストを編集しながらブラウザで仕上がりを確認する。
- 既存のカードデータをもとにカード画像を描画し、**カード詳細ページやデッキリスト**に表示する。
- Node.js で複数のカードを順に描画し、PNG を**一括で書き出す**。

## 使い始める

[Playground](../playground/) でサンプルデータを編集し、プレビューや画像のダウンロードを試せます。自分のプロジェクトに組み込む場合は、[インストール](./index.md)を参照してください。
