# 项目介绍

Yugioh Card 是一个基于 LeaferJS 的开源游戏王卡片渲染库。传入卡名、卡图、正文等数据后，库会按所选版式绘制卡面。

支持游戏王、超速决斗、游戏王卡背、场地中心卡和游戏王第 2 期五种版式。各版式的字段和示例见 [API 参考](../reference/)。

## 可以用来做什么

- 制作**卡片编辑器**，在浏览器中修改卡名、卡图或文本并实时预览。
- 为**卡片详情页或卡组页面**生成卡面，复用已有的卡片资料。
- 在 Node.js 中**批量出图**，把多张卡片依次渲染并导出为 PNG。

## 开始使用

可以在 [Playground](../playground/) 修改示例数据、预览并下载卡图。要把渲染功能集成到自己的项目，请查看[安装指南](./index.md)。
