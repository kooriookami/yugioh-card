# Introduction

Yugioh Card is an open-source library for rendering Yu-Gi-Oh! cards with LeaferJS. Pass in card data such as the name, artwork, and card text to draw a card in the layout you choose.

The five supported layouts are Yu-Gi-Oh!, Rush Duel, Yu-Gi-Oh! Card Back, Field Center Card, and Yu-Gi-Oh! Series 2. For the fields and examples for each layout, see the [API reference](../reference/).

## What you can build

- Build a **card editor** that updates the browser preview as users edit a card's name, artwork, or text.
- Render existing card data for **card detail pages or deck lists**.
- **Export images in batches** by rendering several cards in Node.js and saving them as PNGs.

## Get started

Edit sample data, preview the result, and download a card image in the [Playground](../playground/). To add card rendering to your own project, see [Installation](./index.md).
